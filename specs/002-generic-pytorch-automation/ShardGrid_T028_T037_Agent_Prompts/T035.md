## T035 — Emit capture backend failures

```text
Phase: Phase 3
Priority: P1
Depends on: T011, T034
Files:
- src/shardgrid/planner/generic_graph.py
- tests/integration/test_entrypoint_capture.py
- tests/unit/test_generic_graph_ir.py
```

目标：实现 graph capture backend 的安全 fallback 和结构化 unsupported diagnostics。

Backend 顺序固定为：

```text
1. 优先 torch.export
2. export 无法证明安全语义时，对适合的简单模型 fallback 到 FX symbolic tracing
3. 使用 export/Dynamo/FX diagnostics 分类失败
4. 两者都不能证明 graph semantics 时，在 distributed mutation 前停止
```

必须能够产生/传播这些明确诊断：

```text
GRAPH_BREAK_UNSUPPORTED
CUSTOM_OP_UNSUPPORTED
DYNAMIC_CONTROL_FLOW_UNSUPPORTED
```

必要时保留上层 `MODEL_CAPTURE_UNSUPPORTED` 总类，但不能把不同原因都压成 generic exception / NO_FEASIBLE_PLAN。

实现要求：

- graph break：保留可操作的原因/evidence；
- custom op：能识别时记录 op 名称或相关 evidence；
- data-dependent/dynamic Python control flow：明确分类；
- unsupported capture 必须发生在 distributed mutation 前；
- 不允许为了让模型通过而加入 model-name special case；
- 不允许在 capture 失败后静默构造不完整 graph。
