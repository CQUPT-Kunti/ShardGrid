## T028 — Test run command parsing

```text
Phase: Phase 3 — Entrypoint Capture / Launch

- src/shardgrid/cli/app.py              # 只读基线

```

目标：在实现 `shardgrid run` 前建立 CLI contract tests。

必须按 `contracts/cli.md` 固定以下合同：

```bash
shardgrid run [--config CLUSTER_CONFIG] [--dry-run] [--json] ENTRYPOINT [ARGS...]
```

测试必须覆盖：

1. `ENTRYPOINT [ARGS...]` 原样保留，用户脚本参数不能被 ShardGrid 重解释或吞掉；
2. ShardGrid 自己的 `--config`、`--dry-run`、`--json` 能正确解析；
3. cluster config 与用户脚本自己的 `--config` 能同时存在，例如：
   ```bash
   shardgrid run --config cluster.yaml train.py --config config.yaml
   ```
4. 正常、参数错误、执行失败的 exit code 基线；
5. failure display 的 contract seam，至少能验证 stage/code/message/artifact-log reference 的展示接口；
6. 现有 `train` 命令不能被破坏。

本任务是 **contract-first**。如果 `run` 尚不存在，允许测试先体现待实现合同；但不要在 T028 实现生产 `run` 命令。测试必须精确到 CLI 行为，不要只检查源码字符串。
