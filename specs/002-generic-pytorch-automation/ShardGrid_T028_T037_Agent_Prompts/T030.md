## T030 — Create normal user script fixtures

```text
Phase: Phase 3
Priority: P0 BLOCKING
Depends on: T027
Files:
- tests/fixtures/ordinary_training_scripts/
```

目标：创建真正“普通用户项目风格”的 PyTorch `train.py` fixtures，用于后续 capture 验证。它们不能 import ShardGrid 用户 API。

必须包含正常训练组成：

```text
nn.Module
Dataset/DataLoader 或等价 batch 来源
optimizer
loss
backward
optimizer.step
可观察的 checkpoint intent
```

fixture 集合必须覆盖至少这些调用/数据形态：

- positional args；
- kwargs；
- tuple/list batch；
- dict / nested mapping batch；
- mask + labels；
- Hugging Face 风格 mapping；
- multiple model outputs；
- 至少一个 scheduler 或可观察训练生命周期示例。

约束：

1. 每个脚本都必须能直接用 `python train.py ...` 运行；
2. 不允许 `ModelProvider`、`sample_inputs()`、ShardGrid wrapper、Zoo factory；
3. 模型保持小型，CPU 快速执行；
4. fixture 的目标是模拟普通工业 PyTorch 代码，不是为了 ShardGrid 捕获方便而改写 forward；
5. 不实现 capture 逻辑，那属于 T031/T032。

- 不要求用户实现 `ModelProvider`、`build_model()`、`sample_inputs()`、`compute_loss()` 或 ShardGrid 专用模型接口。
