## T036 — Preserve training lifecycle boundary

```text
Phase: Phase 3
Priority: P1
Depends on: T032, T033
Files:
- src/shardgrid/bootstrap/runner.py
- tests/integration/test_entrypoint_capture.py
```

目标：让 captured context 对用户训练 lifecycle 有足够语义，供后续 Generic Runtime 保留或明确拒绝，而不是只知道 `model + batch`。

在可观察范围内捕获并验证：

```text
optimizer class
optimizer param-group structure
optimizer hyperparameters
gradient accumulation boundary
AMP/autocast/scaler intent
scheduler existence and step boundary
loss/backward boundary
optimizer.step boundary
checkpoint intent
```

实现原则：

1. 用户脚本仍负责声明 optimizer/loss/scheduler/callback/checkpoint intent；
2. 后续 ShardGrid Runtime 才负责 partitioned backward / optimizer execution；本任务只捕获和验证 lifecycle metadata；
3. param groups 必须能映射回 canonical state IDs / captured state keys；
4. 如果 optimizer 存在隐藏 mutation、自定义 side effect、无法安全映射的参数更新语义，必须在 distributed mutation 前返回 structured unsupported failure；
5. 不要假装支持无法观察或无法重放的 callback/scheduler 行为；明确记录 unsupported/partial-support；
6. optimizer-state consolidation 不属于本阶段，也不要实现。
