## T032 — Execute user entrypoint under ShardGrid bootstrap

```text
Phase: Phase 3
Priority: P0 BLOCKING
Depends on: T029, T031
Files:
- src/shardgrid/bootstrap/runner.py
- tests/integration/test_entrypoint_capture.py
```

目标：实现内部 bootstrap，在**同一进程**中运行普通用户 entrypoint，并捕获第一步训练上下文。

实现要求：

1. 执行用户脚本时保留原始：
   ```text
   argv
   cwd
   environment
   Python import/runtime context
   ```
2. 通过 ShardGrid 内部 hook/interception 观察真实 `nn.Module`、第一批真实 batch、model call `args/kwargs`；
3. 不要求用户写 factory、sample builder、wrapper、ShardGrid subclass；
4. 捕获第一步时记录 T031 contract 所需信息；
5. `--dry-run` 下必须在任何 distributed parameter mutation / formal training mutation 前停止；
6. bootstrap 不能把普通用户脚本替换成 ShardGrid 自己的训练 loop；它先观察并建立可支持的训练语义边界；
7. 不在本任务实现 capture-context 文件持久化（T033）；
8. 不在本任务接入 JobManager（T034）。

注意：不要用静态 import + `build_model()` / `sample_inputs()` 作为生产方案。plan 已明确拒绝这种专用模型合同。
