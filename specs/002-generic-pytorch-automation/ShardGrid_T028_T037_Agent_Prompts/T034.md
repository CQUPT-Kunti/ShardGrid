## T034 — Hand captured context to control plane

```text
Phase: Phase 3
Priority: P0 BLOCKING
Depends on: T022, T033
Files:
- src/shardgrid/control/job_manager.py
- tests/integration/test_entrypoint_capture.py
- tests/integration/test_train_orchestration.py
```

目标：让 `JobManager` 对 `shardgrid run` 使用 **capture-first planning**，直接消费已持久化 captured context，而不是退回 model-name / Zoo workload。

实现要求：

1. 保持现有 `JobManager.run(config_path, dry_run=...)` / 现有 `train` 路径兼容；
2. 增加最小的新 entrypoint/capture path，不做大规模 JobManager 重写；
3. `shardgrid run` 路径加载 `plan/capture-context.json` 及相关 artifacts；
4. captured model/call/state metadata 必须真正到达 graph/profile/planner code；
5. **禁止 fallback 到**：
   ```text
   model.type
   zoo_model
   build_zoo_model()
   make_zoo_sample()
   ```
   来重建 workload；
6. dry-run 应执行 capture → graph/profile/planner/admission 所需安全链路，但不 formal training mutation；
7. 任何 capture artifact 缺失/损坏要明确失败，不得静默走旧 Zoo 路径。
