## T033 — Persist captured training context

```text
Phase: Phase 3
Priority: P0
Depends on: T031, T032
Files:
- src/shardgrid/common/serialization.py
- src/shardgrid/artifacts/snapshot.py
- tests/integration/test_entrypoint_capture.py
- tests/integration/test_code_snapshot.py
```

目标：把捕获结果持久化到 Job Snapshot，核心产物：

```text
plan/capture-context.json
```

以及必要的 tensor metadata/reference artifacts。

实现要求：

1. 序列化 metadata 和 artifact reference，**禁止尝试 JSON 序列化任意 live Python object**；
2. `capture-context.json` 至少覆盖 capture contract 中可持久化字段：entrypoint/argv/cwd/env summary、backend evidence、model evidence、batch/call structure schema、tensor metadata、optimizer/lifecycle metadata、state key mapping、unsupported diagnostics；
3. 对 Tensor 内容只保存规划/重放需要的安全 metadata 或受控 artifact reference；不要把任意对象 pickle 进 JSON；
4. 输出路径进入现有 snapshot/plan artifact 体系，不新建第二套 snapshot 系统；
5. serialization 顺序/字段必须足够 deterministic，使 planner/runtime 能稳定读取和 fingerprint；
6. 保持现有 snapshot regression。
