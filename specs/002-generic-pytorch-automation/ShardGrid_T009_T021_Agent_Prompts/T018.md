# 任务目标

更新 `compile_runtime_plan()` / WorkerOwnership，让 Worker ownership 来自 LogicalPartition + explicit state IDs，而不是 module slices；同时严格保留 Planner 的 worker/rank/GPU placement。

# 允许修改的主要文件

```text
src/shardgrid/runtime/dag.py
tests/unit/test_dag_runtime.py
```

# 必须按以下方式实现

1. 阅读 `WorkerOwnershipSpec`、`WorkerOwnershipPlan`、`RuntimeEdgeSpec`、`RuntimePlan`、`compile_runtime_plan()`。
2. Worker ownership 必须明确包含：
   - logical partition IDs；
   - exact owned parameter state IDs；
   - exact owned buffer state IDs；
   - 需要的 read-only state（如 contract 已提供）；
   - inbound/outbound runtime edges 或可从 RuntimePlan 精确推导的 edge evidence。
3. 不再根据 module path/slice 推导 worker state。
4. 多个 partition 放在同一 worker/GPU 时合并 ownership，但 canonical state 不能重复 materialize/重复 owner。
5. `compile_runtime_plan()` 必须严格使用 PlacementPlan 的 worker_id/gpu_index/gpu_id；禁止重新 round-robin 或按 rank 自己决定。
6. graph edge 跨 partition 时按 placement 判断 LOCAL/REMOTE；同 worker/GPU local，跨设备 remote。
7. 测试覆盖：一个 Worker 多 partition、parameter+buffer IDs、shared/read state、local/remote edge、exact placement preservation。
