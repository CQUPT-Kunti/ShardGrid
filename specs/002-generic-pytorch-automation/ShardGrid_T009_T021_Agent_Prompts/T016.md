# 任务目标

在 placement/runtime 消费 Planner 输出之前增加 final-plan invariant validation，并为 graph、ownership、logical partitions、placement 建立一致的 fingerprint/evidence。Exact-plan invariant 违反时必须产生 `PLAN_VALIDATION_FAILURE`。

# 允许修改的主要文件

```text
src/shardgrid/planner/planning_contract.py
tests/unit/test_planning_contract.py
```

# 必须按以下方式实现

1. 阅读 `PlanningResult`、`PlanCandidate`、`LogicalPartitionPlan`、`PlacementPlan`、`plan()` 及已有 diagnostics。
2. 增加明确的 final plan validation seam（函数/结果类型按当前模块风格实现），验证：
   - graph fingerprint 与 logical/placement 一致；
   - partition exact node coverage 已满足；
   - state ownership invariant 已满足；
   - placement 引用的 partition 全部存在且不重复遗漏；
   - runtime 所需 fingerprint inputs 可序列化/比较。
3. `PLAN_VALIDATION_FAILURE` 必须只用于 exact-plan invariant 失败，不要把 memory/resource failure 混进来。
4. fingerprint inputs 至少覆盖 graph、ownership、logical partitions、placement；不得使用 Python object identity。
5. 保持现有 planning candidate search 功能；本 Task 不是重写 search。
6. 测试构造 graph/partition/placement fingerprint mismatch、unknown partition placement、missing placement 等失败，并断言 `PLAN_VALIDATION_FAILURE`。
