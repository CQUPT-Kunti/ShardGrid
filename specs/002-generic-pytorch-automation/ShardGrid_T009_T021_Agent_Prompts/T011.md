# 任务目标

把 FX/export graph 中对 Parameter / Buffer 的使用映射到 T009 的 ownership records，建立“execution node 使用 state”的关系，而不是默认 execution node 自己拥有 state。

# 允许修改的主要文件

```text
src/shardgrid/planner/generic_graph.py
tests/unit/test_generic_graph_ir.py
```

# 必须按以下方式实现

1. 使用 T009 的 canonical StateObject 和 T010 的 stable node IDs；不要另造平行 state ID 系统。
2. 重构/扩展 `_node_parameter_paths()`、`_node_buffer_paths()`、`_parameter_uses()` 等相关逻辑，让 node→state use 映射使用 canonical state ID。
3. 必须覆盖：
   - call_module 参数读取；
   - functional/fused operation 使用参数；
   - module instance 重复调用；
   - parameter reuse / tied parameter；
   - buffer reads。
4. 明确允许：state owner 没有独立 execution node；execution node 没有任何 Parameter/Buffer。
5. shared/tied state 的 use sites 必须汇总到同一 canonical state，不得因多个 key 复制成多个独立 owner。
6. 不要在这一 Task 修改 partitioning/memory/runtime；只完成 graph state-use mapping。
7. 测试必须用 T003 普通 PyTorch fixtures 或现有 equivalent fixtures，不能新增 ShardGrid 专用模型 API。
