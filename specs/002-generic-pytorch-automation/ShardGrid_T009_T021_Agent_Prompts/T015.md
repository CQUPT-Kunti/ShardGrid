# 任务目标

升级 partition validation：必须验证 exact node coverage、exact state ownership、boundary value coverage 和 shared/tied safety，并返回明确的结构化失败理由。

# 允许修改的主要文件

```text
src/shardgrid/planner/partitioning.py
tests/unit/test_partition_candidates.py
```

# 必须按以下方式实现

1. 阅读 `validate_partition_candidate()` 和 `CandidateValidationResult` 当前字段/调用方。
2. 增加/完善以下 invariant：
   - 每个 supported execution node 恰好属于一个 partition；
   - 每个 required state 有且只有一个 owner；
   - read-only use 与 owner 不冲突；
   - 每个 cross-partition value 都有 producer、consumer、boundary metadata；
   - shared/tied state 不允许 ambiguous writers/owners。
3. 对 duplicate node、missing node、duplicate state owner、missing state owner、ambiguous shared state、missing boundary 分别返回可区分的 reason/code；不要全部归并为一个模糊字符串。
4. 不要在 T015 重做 candidate generation；只验证 T014 输出。
5. 不要把 semantic validation failure 转成 `NO_FEASIBLE_PLAN`。
6. 测试必须显式构造上述错误 case，并断言 reason 足够具体。
