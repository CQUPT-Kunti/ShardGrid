# 任务目标

建立 CPU Planner compatibility matrix，直接验证普通 PyTorch 模型从 capture → profile → partition → plan → validation 的完整链路，不依赖 Zoo 和真实 GPU。

# 允许修改的主要文件

```text
tests/unit/test_generic_planner_compatibility.py
tests/fixtures/generic_training_models.py
```

# 必须按以下方式实现

1. 使用 `tests/fixtures/generic_training_models.py` 的 ordinary PyTorch fixtures；不要引入 Model Zoo。
2. 新建/完善 `tests/unit/test_generic_planner_compatibility.py`，为每个 family 跑同一条 planner pipeline：
   `capture -> graph/state ownership -> profile -> partition candidate -> final plan validation`。
3. 至少覆盖：Sequential、Residual、CNN、UNet-like、Dense、Transformer、Attention、Encoder-Decoder、Multi-Branch、Shared Module。
4. 共享/绑权重如属于 supported read semantics，应测试 PASS；明确 unsafe shared writes 或 dynamic behavior 可以测试为 expected unsupported，但必须断言具体 unsupported reason。
5. 禁止用 xfail 隐藏普通 supported model 的 Planner bug。
6. 测试不得需要 CUDA、SSH、真实 GPU；使用 CPU/fake ResourceSnapshot 构造 placement 所需资源。
7. 每个 model family 的 assertion 至少验证：graph 非空、node coverage、state ownership、partition candidate、plan validation。
8. 如果某 family 失败，先确认是否是 T009-T019 语义实现缺陷；若需要回改前序代码，允许修正真正回归但必须只修 Phase1 相关生产文件，并在最终 diff/commit 中准确说明。
