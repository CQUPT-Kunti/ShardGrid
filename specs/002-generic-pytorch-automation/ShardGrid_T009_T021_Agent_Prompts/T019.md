# 任务目标

让 runtime partition extraction 使用 stable execution-node/value IDs 映射 backend graph，而不是仅依赖“canonical nodes 与 FX nodes 数量/zip 顺序相同”。任何不一致必须 fail closed 为 `PLAN_VALIDATION_FAILURE` 语义。

# 允许修改的主要文件

```text
src/shardgrid/runtime/partition_graph.py
tests/unit/test_dag_runtime.py
```

# 必须按以下方式实现

1. 阅读 `extract_partition_graph()` 当前 `zip(graph.nodes, fx_nodes)`、node count alignment、value mapping。
2. 建立 stable canonical node/value ID → backend FX node 的映射；不要把“相同数量 + zip”当唯一一致性证明。
3. 映射必须验证 node identity/target/op/必要 metadata 与 captured canonical graph 对应；不能静默猜测。
4. partition.input/output value IDs 必须通过 canonical value mapping 解析。
5. 遇到 unknown node ID、value producer mismatch、backend graph mismatch 时拒绝执行；使用项目当前 structured validation/error seam 表达 `PLAN_VALIDATION_FAILURE`（不要 runtime repartition）。
6. 保持提取出的 `GraphModule` input/output contract 与 LogicalPartitionSpec 一致。
7. 测试覆盖：正常 stable-ID extraction、backend node reorder/mismatch、unknown ID、value mismatch；错误必须 fail closed。
