Phase: Phase 6

## 目标

JobManager / SSH launcher 必须保留真实 failure cause 与 retry policy，不再把 memory、resource、network、launch、runtime 混成一个错误。

必须明确区分：

```text
MEMORY_REJECT
FORMAL_TRAINING_OOM
RESOURCE_CHANGED
NETWORK_FAILURE
RENDEZVOUS_FAILURE
PROCESS_LAUNCH_FAILURE
INFRA_FAILURE
RUNTIME_FAILURE
```

## Retry 语义

```text
MEMORY_REJECT
→ retryable candidate feedback
→ cleanup
→ next candidate

RESOURCE_CHANGED
→ retryable after fresh discovery/replan

transient NETWORK/RENDEZVOUS/PROCESS_LAUNCH/INFRA
→ 可按实际 policy retry

FORMAL_TRAINING_OOM
→ 不得当成正常 candidate reject
→ non-retryable safety/runtime failure
```

SSHLauncher 应附加适用的 rank/worker/log context。

Network/rendezvous/process failure 绝不能伪装成：

```text
MEMORY_REJECT
GPU_MEMORY_SATURATION
```
