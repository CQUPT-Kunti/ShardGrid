# T056 — Show actionable CLI diagnostics

Phase: Phase 6  
Priority: P1  
Depends on: T053, T055

Files:

```text
src/shardgrid/cli/commands/run.py
src/shardgrid/cli/commands/train.py
tests/integration/test_run_cli.py
tests/integration/test_train_cli.py
```

## 目标

`shardgrid run` 和兼容 `shardgrid train` 输出结构化 failure 信息，让用户无需先读 raw logs 就能识别失败阶段。

必须展示/输出：

```text
stage
code
retryable
producer（若用户面/JSON contract包含）
artifact/log references
```

JSON 模式必须保持 machine-readable，不能只输出人类字符串。

## 约束

- 不打印 `tests/address.json` 中的密码或认证内容。
- 不把 structured code 再退化成解析 message。
- 文本模式可以友好格式化，但不能丢失 exact code。
- 现有 CLI exit-code contract 保持兼容。

## 测试

实际执行：

```bash
pytest tests/integration/test_run_cli.py tests/integration/test_train_cli.py
```

如果 integration tests 被默认 skip，按仓库现有规则启用 integration，确保本 Task 场景实际执行。

Acceptance：

```text
CLI_FAILURE_STAGE_VISIBLE=PASS
CLI_FAILURE_CODE_VISIBLE=PASS
CLI_JSON_MACHINE_READABLE=PASS
```

本 Task 不要求实机。
