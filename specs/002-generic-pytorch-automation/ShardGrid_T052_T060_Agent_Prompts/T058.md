# T058 — Treat equal step counts as stall

Phase: Phase 6  
Priority: P0 BLOCKING

## 目标

修复 stress no-progress 判定：

```text
after_steps == before_steps
```

必须被视为：

```text
NO_PROGRESS / stall evidence
```

不能算作“仍然健康”。

同时保留：

```text
after_steps < before_steps
```

作为 step regression / stronger failure evidence。

正确逻辑：

```text
after > before   → progress
after == before  → no progress / stall
after < before   → regression/failure
```

## 约束

- 不用 wall-clock 活着、PID 存在或日志持续打印替代 optimizer-step progress。
- 不为了让 stress 继续而手工杀掉已成功 Job 释放显存。
- 不提前实现 T059 saturation proof。
