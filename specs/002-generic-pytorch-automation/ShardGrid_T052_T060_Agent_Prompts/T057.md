## 目标

先用 integration tests 固定 stress runner 的分类语义，避免继续依赖 message substring 猜原因。

本 Task 测试必须区分：

```text
dry-run / validation failure
probe MEMORY_REJECT
SEARCH_BUDGET_LIMIT
CPU_PROCESS_SATURATION
GPU_MEMORY_SATURATION
INFRA / network / launch failure
RUNTIME_FAILURE
TEST_LIMIT_REACHED / SATURATION_NOT_PROVEN（适用场景）
```

Stress runner 应消费 structured failure code/stage/evidence，而不是：

```python
if "out of memory" in message:
    ...
```

这种主路径判断。
