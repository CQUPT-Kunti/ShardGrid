# T052 — Define failure taxonomy

Phase: Phase 6  
Priority: P0 BLOCKING  
Depends on: T051

Files:

```text
src/shardgrid/common/enums.py
tests/contract/test_failure_records.py
```

## 目标

在现有 broad `FailureStage` 基础上增加结构化 failure-code enums，使 `contracts/failures.md` 中所有精确 code 都可以表达。

## 必须实现

不得删除/破坏现有 broad stage 兼容性。

必须能够表达：

```text
MODEL_CAPTURE_UNSUPPORTED
GRAPH_BREAK_UNSUPPORTED
CUSTOM_OP_UNSUPPORTED
DYNAMIC_CONTROL_FLOW_UNSUPPORTED

PROFILE_FAILURE
PARTITION_FAILURE
PLAN_VALIDATION_FAILURE
NO_FEASIBLE_PLAN
SEARCH_BUDGET_LIMIT

MEMORY_REJECT
FORMAL_TRAINING_OOM
RESOURCE_CHANGED

NETWORK_FAILURE
RENDEZVOUS_FAILURE
PROCESS_LAUNCH_FAILURE
INFRA_FAILURE
RUNTIME_FAILURE

CPU_PROCESS_SATURATION
GPU_MEMORY_SATURATION
TEST_LIMIT_REACHED
SATURATION_NOT_PROVEN
```

命名/序列化应稳定，适合持久化与 CLI/JSON 使用。

## 禁止

- 不把所有错误继续塞进 `NO_FEASIBLE_PLAN`。
- 不重构整个 errors subsystem；本 Task 只建立 taxonomy enum/contract。
- 不提前实现 T053 producer/retry/log metadata。
