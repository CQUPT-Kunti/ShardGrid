# T053 — Persist structured failure metadata

Phase: Phase 6

## 目标

让 failure record 真正持久化结构化字段，并保持旧 failure record 兼容。

必须支持 round-trip：

```text
code
stage
producer
retryable
message
rank
worker_id
gpu_id
log refs
artifact refs
```

## 关键约束

- 老记录缺少新增字段时仍可读取，不能因为 schema 扩展直接崩溃。
- 新记录序列化→反序列化后结构化字段不丢失。
- rank/worker/GPU context 只在适用时填写，不制造假值。
- 日志/artifact reference 保存引用，不嵌入凭据或敏感连接信息。
- retryable 是显式语义，不从 message substring 猜测。
