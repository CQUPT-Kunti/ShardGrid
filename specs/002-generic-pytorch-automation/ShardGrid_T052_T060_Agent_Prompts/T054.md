# T054 — Preserve capture/planner failure causes

Phase: Phase 6  
Priority: P0 BLOCKING  
Depends on: T035, T052, T053

Files:

```text
src/shardgrid/planner/generic_graph.py

```

## 目标

Capture / graph / partition semantic failures 不再统一冒充：

```text
NO_FEASIBLE_PLAN
```

Producer stage 与 failure code 必须匹配。

## 必须映射

Capture / graph：

```text
GRAPH_BREAK_UNSUPPORTED
CUSTOM_OP_UNSUPPORTED
DYNAMIC_CONTROL_FLOW_UNSUPPORTED
MODEL_CAPTURE_UNSUPPORTED   # 若当前 producer 适用
```

Planner：

```text
PROFILE_FAILURE
PARTITION_FAILURE
PLAN_VALIDATION_FAILURE
NO_FEASIBLE_PLAN
SEARCH_BUDGET_LIMIT
```

重点区分：

- unsupported graph semantics；
- partition candidate coverage/invariant failure；
- plan validation failure；
- 真正搜索后无 feasible plan；
- bounded search budget 用尽。

`SEARCH_BUDGET_LIMIT` 不能被包装成 `GPU_MEMORY_SATURATION`。

## 禁止

- 不通过解析异常 message substring 决定 producer。
- 不把 graph semantic error 降级成 placement/no-feasible。
- 不改变前面已经建立的 ExecutionGraph / state ownership 架构。
