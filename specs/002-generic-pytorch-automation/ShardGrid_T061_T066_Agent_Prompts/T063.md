# T063 — Validate multi-GPU partition execution

Phase: Phase 7  
Priority: P0 BLOCKING  
Depends on: T062

文件：

```text
tests/multi_host/test_generic_multi_gpu.py
```

## 目标

使用至少两个真实、fresh-discovered GPU 验证 Generic Runtime 的多 GPU partition 执行。

必须验证：

```text
exact planner placement
activation transfer
gradient transfer
optimizer progress
checkpoint shard + merge
```

## 硬约束

- 使用 non-zoo 普通 PyTorch fixture。
- 至少两个真实 GPU 实际参与；单 GPU 多进程不能冒充 multi-GPU。
- GPU 可以位于当前 discovery 可用的合法拓扑中；测试不得手工重写 Planner placement。
- `original-parallel-plan.json` 与 Runtime mapping 必须一致。
- 必须保留：
  - `PLAN_RUNTIME_CONSISTENCY_CHECK=PASS`
  - Worker-only materialization
- 必须证明存在真实跨 Partition activation/gradient transfer，而不是所有 Partition 恰好落在一个 Worker。
- optimizer steps 必须真实增长。
- checkpoint merge 必须成功，最终 state 可 strict reload。
- Formal CUDA OOM 必须为 0。
- 若 multi-GPU 路径出现 network/launch/runtime 错误，必须按结构化 failure taxonomy 分类。

执行：

```bash
pytest tests/multi_host/test_generic_multi_gpu.py
```

必须使用仓库现有 hardware/multi-host opt-in 机制真实运行；skip 不算 PASS。

Acceptance：

```text
MULTI_GPU_GENERIC=PASS
```

如果当前 fresh discovery 只有一个可用 GPU：

```text
STATUS=BLOCKED
REASON=真实 multi-GPU acceptance 条件不足
```

不得降级成单 GPU PASS。
