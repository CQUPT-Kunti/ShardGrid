# T062 — Validate single GPU runtime and memory probe

Phase: Phase 7  
Priority: P0 BLOCKING  
Depends on: T061

文件：

```text
tests/hardware/test_generic_single_gpu.py
```

## 目标

在**真实 CUDA GPU**上证明 non-zoo 普通 PyTorch script 的完整单 GPU Generic 路径：

```text
normal train.py
→ capture
→ generic graph/planning
→ real one-batch memory probe
→ formal training
→ optimizer progress
→ worker shard / merge
→ model-state.pt
→ original_model.load_state_dict(..., strict=True)
```

## 必须验证

- 使用 T061 fresh discovery 得到的当前 healthy/reachable GPU；不要硬编码 IP/GPU。
- 测试模型必须是 non-zoo fixture，不得通过 model-name-specific Runtime。
- CUDA 确实被使用；不能用 CPU fallback 代替。
- memory probe 实际执行，并有 actual memory evidence。
- Probe PASS 后 formal training 实际运行并产生 optimizer step progress。
- `FORMAL_TRAINING_OOM_COUNT=0`。
- 最终标准 `model-state.pt` 真实 `strict=True` reload，`missing_keys=[]`、`unexpected_keys=[]`。
- Parameter 与 Buffer 都覆盖。
- hardware marker 必须保护默认本地 test suite，但本 Task 执行时必须显式 opt-in，不能让它 skip。

执行：

```bash
pytest tests/hardware/test_generic_single_gpu.py
```

如需硬件 opt-in 参数，先从仓库 `pytest`/`conftest` 配置确定真实用法，再执行。
