## 目标

在至少两个真实可达 Host 上，经**生产 SSH Launcher**完成 non-zoo Generic 训练。

必须实际证明：

```text
SSH
→ live network/preflight
→ rendezvous
→ remote worker launch
→ distributed generic runtime
→ activation/gradient transfer
→ optimizer progress
→ remote logs
→ checkpoint shards
→ Control Plane merge
→ strict reload
→ worker cleanup
```

- Host 连接信息从 `tests/address.json` 读取，但实际 usable hosts 由 fresh discovery/live preflight 决定。
- 不硬编码“必须使用某两个 IP”；自动从当前 reachable/healthy 资源中选择合法计划。
- SSH 是本阶段正式兼容 gate。
- 不新增或替换为 Kubernetes / Volcano / HAMi 路径。
- exact plan 必须原样执行。
- Runtime/Planner partition/materialized state 映射一致。
- 至少一个 non-zoo 模型完成真实 SSH multi-host formal training。
- 所有 active worker 的 optimizer progress 有真实 evidence。
- shard merge + `strict=True` reload PASS。
- remote logs 可定位。
- 测试结束后，只清理本测试 worker/probe/training 进程和 reservation。
- `FORMAL_TRAINING_OOM_COUNT=0`。
