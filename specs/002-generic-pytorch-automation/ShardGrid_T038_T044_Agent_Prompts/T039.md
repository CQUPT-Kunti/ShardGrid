# T039 — Compile Generic Runtime Plan

Feature: `002-generic-pytorch-automation`

```text
T039 [US3] — Update compile_runtime_plan()
Phase: Phase 4
Priority: P0 BLOCKING
Depends on: T018, T019, T038
```

## 目标

更新 `src/shardgrid/runtime/dag.py::compile_runtime_plan()`，让 Runtime Plan 直接消费：

```text
Captured ExecutionGraph
LogicalPartition
OwnershipModel / WorkerOwnershipPlan
Exact PlacementPlan
Boundary values / runtime edges
Planner fingerprint
```

Runtime Plan 必须完整携带 exact partition、owner、placement 和 edge metadata。

## 涉及文件

```text
src/shardgrid/runtime/dag.py
tests/unit/test_runtime_exact_plan.py
```

必要时只修改与 runtime-plan compilation 紧密相关的数据结构；不要扩展到 T040 materialization。

## 实施约束

- 信任 Planner 的稳定 IDs，不做 rank-local rediscovery。
- fingerprint / graph / plan 不匹配时必须拒绝执行，不能静默修正。
- 不允许重新调用 partition planner。
- 不允许重新 placement。
- 不允许 round-robin。
- 保持一个 Worker 可拥有多个非连续 Logical Partitions。
- runtime edge 必须保留 producer/consumer 和 boundary value metadata。
- 保持现有 `PLAN_RUNTIME_CONSISTENCY_CHECK` 语义。

## 测试

```bash
pytest tests/unit/test_runtime_exact_plan.py tests/unit/test_dag_runtime.py
```

Acceptance：Runtime Plan 中的 partition IDs、state ownership、worker/rank/GPU placement、edges 与 Planner 输出严格一致。
