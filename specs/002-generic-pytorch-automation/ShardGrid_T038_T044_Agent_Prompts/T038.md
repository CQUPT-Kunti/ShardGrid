## 实施要求

先阅读现有 `compile_runtime_plan()`、Worker ownership 和 partition graph extraction。测试必须明确防止以下回归：

- Runtime 再次 repartition；
- Runtime 根据 rank/world_size 做 round-robin；
- Runtime 重新选择 GPU / placement；
- Runtime 丢失 Planner state ownership；
- Runtime 使用与 plan 不一致的 graph/plan fingerprint。

优先使用 T009-T021 已建立的 stable graph IDs、state IDs、LogicalPartition 和 WorkerOwnershipPlan fixture。

本 Task 核心是建立 exact-plan contract test；**不要提前实施 T039 的 runtime-plan 重构**。如果当前实现与合同不一致且无法只在 T038 范围解决，报告 BLOCKED，不要偷偷完成 T039。
