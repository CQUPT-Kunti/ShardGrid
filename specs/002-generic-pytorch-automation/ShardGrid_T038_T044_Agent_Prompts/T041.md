# T041 — Local Generic Runtime Integration

Feature: `002-generic-pytorch-automation`

```text
T041 [US3] — Add local runtime integration tests
Phase: Phase 4
Priority: P0 BLOCKING
Depends on: T039, T040
```

## 目标

使用 **非 Zoo、普通 PyTorch training script fixture** 验证本地 Generic Runtime 可以完成一个真实训练 step：

```text
forward
-> backward
-> optimizer.step
-> progress evidence
-> checkpoint shard
```

## 涉及文件

```text
tests/integration/test_generic_runtime_local.py
tests/fixtures/ordinary_training_scripts/
```

必要时允许对 Phase 4 Runtime 做当前 Task 所需的最小 integration 修复，但不要进入 Phase 5 checkpoint genericization。

## 实施要求

- fixture 必须是普通 PyTorch 写法，不得使用 `build_zoo_model()` / `make_zoo_sample()`。
- 使用 T028-T037 capture artifacts 和 T039/T040 exact Runtime Plan。
- 验证真实 Tensor 数据沿 partition graph 流动。
- backward 必须传播到拥有 state 的 Worker/partition。
- optimizer step 必须产生可验证的参数更新 / step progress。
- 至少生成当前 runtime 支持的 worker checkpoint shard evidence。
- CPU/local 为主，不要求 CUDA/SSH。

## 测试

```bash
pytest tests/integration/test_generic_runtime_local.py
```

Acceptance：至少一个普通非 Zoo 模型完成一个 supported generic local training step。

## 禁止

不要开始 T042 SSH；不要为测试模型增加 production special-case；不要实现 Phase 5 的最终 standard state_dict merge。
