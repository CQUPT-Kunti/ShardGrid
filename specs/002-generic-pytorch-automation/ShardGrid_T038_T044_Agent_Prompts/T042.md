# T042 — Generic Runtime SSH Launch

Feature: `002-generic-pytorch-automation`

```text
T042 [US3] — Integrate generic runtime launch command
Phase: Phase 4
Priority: P1
Depends on: T024, T039
```

## 目标

更新 SSH launcher，使远程 Worker 启动 Generic Runtime bootstrap，并把 **exact artifacts 路径**传给 Worker。

## 涉及文件

```text
src/shardgrid/launchers/ssh.py
tests/contract/test_ssh_launcher.py
tests/unit/test_memory_probe_launch.py
```

## 必须传递的核心信息

根据当前实现和 T039 runtime contract，至少保证 Worker 可以定位：

```text
exact plan artifact
captured context / graph artifact
worker assignment / rank
runtime bootstrap entry
```

不要让 SSH launcher 重新解释 partition/placement。

## 兼容性约束

必须保持现有：

```text
_launch_argv()
_launch_env()
rank/world behavior
CUDA env behavior
rendezvous/network env semantics
```

不要因为 Generic Runtime 改变正确的 rank/world/CUDA_VISIBLE_DEVICES 语义。

Launch command 最终应引用 Generic Runtime bootstrap + exact plan/context artifacts，而不是 example/model-name runtime。

## 测试

```bash
pytest tests/contract/test_ssh_launcher.py tests/unit/test_memory_probe_launch.py
```

Acceptance：SSH launch contract 能证明 exact artifacts 被正确传递，同时既有 rank/world/CUDA env 回归保持 PASS。

## 禁止

不要实施 T043 admission 逻辑；不要修改 Planner plan；不要加入 model-name dispatch。
