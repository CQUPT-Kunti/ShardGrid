# T040 — Worker Owned-State Materialization

Feature: `002-generic-pytorch-automation`

```text
T040 [US3] — Update worker materialization
Phase: Phase 4
Priority: P0 BLOCKING
Depends on: T039
```

## 目标

让 Worker 只 materialize `WorkerOwnershipPlan` 明确拥有的真实 Parameter / Buffer。

```text
owned state -> real tensor/state
non-owned skeleton -> meta/fake where safe
```

最终 Worker 实际 materialized parameter/buffer 集合必须与 Planner ownership 完全一致。

## 涉及文件

```text
src/shardgrid/runtime/dag.py
tests/unit/test_runtime_exact_plan.py
```

## 必须覆盖

- owned parameter；
- owned buffer；
- read-only state use；
- shared/tied state 的唯一 canonical owner；
- parameterless execution node；
- 一个 Worker 多 Logical Partitions；
- 非拥有 state 不得重复 materialize。

Shared/tied state 不允许因为多个 graph use site 而复制成多个 optimizer owner。

## 关键约束

Worker materialization 必须来源于 Planner 的 explicit state IDs / WorkerOwnershipPlan，不得重新从 module slice、`named_modules()` 或 rank 推导 ownership。

不要改变 Placement；不要让 Worker 自己决定“我应该加载什么”。

## 测试

```bash
pytest tests/unit/test_runtime_exact_plan.py
```

Acceptance：实际 materialized Parameter/Buffer IDs 与 WorkerOwnershipPlan 完全一致，并继续保持 exact-plan consistency。
