# T043 — Preserve Generic Runtime Memory-Probe Flow

Feature: `002-generic-pytorch-automation`

```text
T043 [US3] — Preserve memory probe candidate flow
Phase: Phase 4
Priority: P0 BLOCKING
Depends on: T017, T042
```

## 目标

让 Generic Runtime 接入后继续保持现有正确 admission 链：

```text
Static Estimate
+ Online Calibration
+ Bounded Candidate Search
+ Real One-Batch Memory Probe
-> Probe PASS 才进入 Formal Training
```

## 涉及文件

```text
src/shardgrid/control/job_manager.py
tests/unit/test_memory_probe_launch.py
tests/unit/test_job_manager_live_probe.py
```

## 核心语义

- Candidate A `MEMORY_REJECT`：清理该 candidate 的临时资源，然后继续 Candidate B。
- Probe failure 不能直接判整个 Job 不可行，除非候选搜索真正耗尽。
- `RESOURCE_CHANGED` / infra/runtime error 不得伪装成显存不足。
- Formal Training CUDA OOM 仍属于错误，不是正常 saturation。
- 每个 probe candidate 使用 fresh execution/resource/network/port evidence。
- Probe 必须使用 T042 的 Generic Runtime launch path 和 exact artifacts。

## 禁止

不要重新引入：

```text
minimum_runtime_reserve_bytes
uncertainty_headroom_ratio
第二套固定 reserve/headroom admission
```

不要因为第一个 candidate Probe fail 就结束整个 Job。

## 测试

```bash
pytest tests/unit/test_memory_probe_launch.py tests/unit/test_job_manager_live_probe.py
```

Acceptance：`MEMORY_REJECT` 只拒绝 candidate，并在 bounded search 尚有候选时继续；Formal Training OOM 路径仍按错误处理。

## 范围

本 Task 不做 T052+ failure taxonomy 全面重构，只保持 Phase 4 Generic Runtime 下既有 probe/admission 语义。
