## 目标

修复 ordinary entrypoint 的模型/状态捕获，使：

```text
用户仍然写普通 PyTorch
model = HugeModel(...)
        ↓
ShardGrid capture bootstrap 在真实大 Parameter storage 创建前拦截/替代表达
        ↓
得到 graph/state metadata
        ↓
Planning 不需要完整真实模型进入 Control Plane RAM
```

必须满足：

```text
CONTROL_PLANE_FULL_MODEL_BEFORE_PLAN=0
```

对于无法安全进行 metadata-first capture 的模型：

```text
precise unsupported failure
```

而不是 fallback 到完整 CPU materialization。

## 关键要求

“先完整构造 CPU 模型，再转换到 meta/fake”不算完成。

禁止这种伪实现：

```python
model = HugeModel()      # 已经完整分配 CPU 参数
model.to("meta")
```

也禁止：
- 构造 full model 后取 shape，再释放；
- full `state_dict()` 后只保存 metadata；
- deepcopy full model；
- 要求用户修改成 ShardGrid model factory；
- 按 model name/Zoo 重建。

必须在 ordinary construction 路径上采用：

```text
meta / fake / lazy / equivalent bounded interception
```

具体技术方案以当前代码和 PyTorch 能力为准，不要求某一个固定 API，但必须证明真实 storage 没有先产生。

## State metadata

需要保持/产生后续 Planner 所需的 bounded metadata，例如：

```text
canonical state id
original state_dict key
parameter/buffer kind
shape
dtype
requires_grad
shared/tied storage relationship
owner/use metadata
```

不要在 graph metadata 中重新塞入真实 tensor payload。

注意：`backend-graph.pt` full-state 解耦是后续 Phase 的专门任务；T069 只不要新增更多 full-state coupling，不提前实现 T081+。
