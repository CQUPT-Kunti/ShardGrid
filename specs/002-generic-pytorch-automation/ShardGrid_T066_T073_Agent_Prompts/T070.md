## 目标

移除 Planning 前对真实 CPU training execution 的依赖：

```text
CPU forward = 0
CPU backward = 0
CPU optimizer.step = 0
```

但仍然保留后续 Planner 需要的 bounded lifecycle metadata。

目标不是“什么都不捕获”，而是：

```text
metadata / symbolic / fake / bounded capture
```

代替：

```text
真实 CPU tensor computation
```

## 必须保持的信息

根据现有 Feature contract，supported ordinary entrypoint 仍应得到足够 metadata，例如：

```text
graph/dataflow
input/output structure
shape
dtype
state use mapping
forward/backward lifecycle boundary semantics
optimizer intent/metadata（在能安全证明时）
```

具体表示沿用现有 GenericGraphIR / capture contracts。

## Unsupported 必须 fail closed

如果存在：
- data-dependent dynamic control flow；
- custom op 无安全 fake/meta semantics；
- optimizer side effect 无法静态描述；
- 需要真实 tensor value 才能决定 graph；
- 缺失关键 shape/state metadata；

不要 fallback：

```text
那就在 CPU 上真实跑一次
```

应返回 structured unsupported diagnostic。

T072 会专门验证这些 failure cases；本 Task 应为其提供正确基础。
