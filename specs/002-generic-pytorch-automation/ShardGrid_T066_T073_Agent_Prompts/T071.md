## 非常重要：不要真的造 30G/70G/100G tensor

禁止：

```python
torch.empty(30 * GB)
nn.Parameter(torch.empty(...70GB...))
```

也禁止通过：
- 巨大 `backend-graph.pt`；
- 巨大 CPU batch；
- swap；
- mmap 一个完整真实参数模型再假装安全；
- dummy CUDA reserve buffer；

来满足测试。

这些 fixture 必须验证**架构上的 declared size / metadata-first planning**，不是测试机器有多少物理 RAM。
