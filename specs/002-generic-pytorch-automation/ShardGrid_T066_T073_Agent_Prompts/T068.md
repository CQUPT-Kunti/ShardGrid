## 测试方式

例如可以检测：
- `forward()` 是否真的进入；
- `Tensor.backward()` / autograd path 是否真的执行；
- `optimizer.step()` 是否真的修改状态。

但不要为了检测而制造大 tensor。

必须区分：

```text
metadata/symbolic interception
```

与：

```text
真实数值 CPU execution
```
