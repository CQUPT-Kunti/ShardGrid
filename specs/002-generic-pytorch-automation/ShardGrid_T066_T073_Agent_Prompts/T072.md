## 目标

证明当 ordinary PyTorch workload 无法通过 bounded metadata capture 安全表示时，ShardGrid 会：

```text
fail closed
```

并在任何真实模型 mutation / full materialization / CPU real training fallback 之前返回 structured failure。

必须覆盖任务中要求的代表性 case，实际可行时包括：

```text
dynamic control flow
custom op
optimizer mutation / unsupported optimizer side effect
missing required metadata
```

## 关键原则

Unsupported 的正确行为：

```text
capture attempt
→ detect unsupported semantic
→ structured diagnostic
→ stop before mutation
```

错误行为：

```text
meta/fake capture failed
→ fallback full CPU model
→ real forward/backward
→ 再决定 unsupported
```

这种 fallback 必须被测试禁止。

## Failure taxonomy

优先复用 Feature 002 已有 structured diagnostics / Phase 6 taxonomy。

不要为了 T072 新建一套平行错误系统。

错误必须尽可能指出：
- failing stage；
- concrete unsupported reason；
- 是否发生 mutation；
- 是否发生 full materialization；
- 是否发生 real CPU execution。

不要把 capture unsupported 错误误分类成：
- GPU memory saturation；
- MEMORY_REJECT；
- network failure。

## Scope 边界

T072 不负责“支持所有 dynamic/custom op”。

它只要求：

> 不支持时安全、明确、无危险 fallback。

也不要提前：
- 改 estimator；
- 删除 GPU trial probe；
- 跑 hardware；
- 修 backend-graph full-state（后续 Phase）。
