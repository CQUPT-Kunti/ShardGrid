## 目标

建立测试约束，证明 ordinary PyTorch entrypoint 的目标是：

```text
model declared state > configured control-plane RAM budget
        ↓
Planning 可以开始
        ↓
不需要先把完整真实 Parameter/Buffer materialize 到 CPU
```

核心 Gate：

```text
CONTROL_PLANE_FULL_MODEL_BEFORE_PLAN=0
```

这是测试优先 Task；当前旧实现预计会违反该约束。不要在本 Task 顺手实现 T069。

## Fixture 必须是普通 PyTorch 用户脚本

允许：

```python
model = HugeModelLike(...)
optimizer = ...
```

但测试必须设计成**不会真的申请 30G/70G/100G CPU RAM**。

禁止为了“证明大模型”直接：

```python
torch.empty(30 * GB)
nn.Parameter(torch.empty(70 * GB))
```

把测试机内存打爆。

应该使用 metadata/declaration/synthetic logical size 等 bounded 方式表达“模型声明状态规模大于 RAM budget”，具体方式遵循现有 capture/spec 设计。

禁止新增：

```text
ModelProvider
build_model()
sample_inputs()
ShardGridModel
```
