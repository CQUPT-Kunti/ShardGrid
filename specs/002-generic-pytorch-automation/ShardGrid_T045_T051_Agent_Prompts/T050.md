# T050 — Reject unsafe partial checkpoint bundles

Phase: Phase 5  
Priority: P1  
Depends on: T047

## 目标

补齐 checkpoint failure tests，确保任何不完整、重复、过期或不一致的 shard bundle 在生成误导性 `model-state.pt` 之前失败。

主要文件：

```text
tests/unit/test_checkpoint_generic_state.py
src/shardgrid/runtime/checkpoint.py
```

## 必须覆盖

至少验证拒绝：

- 缺 shard
- 缺 Parameter
- 缺 Buffer
- duplicate canonical ID
- duplicate original state key
- stale graph fingerprint
- plan ID mismatch
- step mismatch
- ownership mismatch
- shape mismatch
- dtype mismatch
- shared/tied owner 冲突

失败必须：

- 明确发生在 checkpoint stage
- 不留下看似成功的 model-state artifact
- 不把错误吞掉或降级为 warning

## 边界

- 不开始 Phase 6 failure taxonomy 全面重构。
- 如果项目当前已有 structured failure 类型，复用；不要在这里重写全局错误体系。
- optimizer state 仍然 Out of Scope。

## 测试

```bash
pytest tests/unit/test_checkpoint_generic_state.py
```

PASS 条件：所有 unsafe bundle 都在 merge/finalize 前明确失败。
