# T047 — Merge shards into standard model state

Phase: Phase 5  
Priority: P0 BLOCKING  
Depends on: T046

## 目标

修改 checkpoint merge，使多个 Worker shards 生成标准：

```text
model-state.pt
```

其中 key 必须与原始 capture 时的 `state_dict` 完全一致。

主要文件：

```text
src/shardgrid/runtime/checkpoint.py
tests/unit/test_checkpoint_generic_state.py
```

## Merge 必须校验

拒绝：

- schema version mismatch
- graph fingerprint mismatch / stale graph
- plan ID mismatch
- step mismatch
- ownership mismatch
- duplicate canonical ID
- duplicate original state key
- missing expected Parameter
- missing expected Buffer
- shape mismatch
- dtype mismatch

Shared/tied state 只能由 canonical checkpoint owner 输出一次。

最终：

```python
state = torch.load("model-state.pt")
```

必须得到普通 PyTorch `state_dict` 风格 mapping，而不是 ShardGrid 私有模型对象。

## 禁止

- merge 时重新 build 模型
- 根据 model type/name 选择合并逻辑
- 为错误 bundle 生成“部分成功”的 model-state artifact
- 实现 optimizer-state consolidation

## 测试

```bash
pytest tests/unit/test_checkpoint_generic_state.py
```

PASS 条件：生成的 `model-state.pt` 已满足 strict-loadable model state contract。
