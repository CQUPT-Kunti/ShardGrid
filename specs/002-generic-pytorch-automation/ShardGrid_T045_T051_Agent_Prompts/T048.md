# T048 — Finalize checkpoints without zoo/model-specific rebuilds

Phase: Phase 5  
Priority: P0 BLOCKING  
Depends on: T047

## 目标

移除生产 checkpoint finalization 中的模型名称/Zoo 重建依赖。

主要文件：

```text
src/shardgrid/control/job_manager.py
tests/unit/test_checkpoint_generic_state.py
tests/unit/test_job_manager_model_coupling.py
```

重点检查：

```text
JobManager._write_consolidated_model()
_finalize_checkpoint_bundle()
以及直接相关 helper
```

## 必须实现

生产 finalization：

```text
Worker shards
→ generic validation
→ generic merge
→ model-state.pt
```

不能再调用：

```text
build_zoo_model(...)
make_zoo_sample(...)
model.type-specific constructor
generic_dag-specific rebuild
```

需要的 strict validation 应基于 capture 时保存的原始 state structure / keys / metadata，而不是重新通过模型名称创建模型。

## Legacy 边界

Plan 明确要求：

- legacy reconstruction 可以暂时保留在兼容/example path
- Phase 5 只要求**生产 finalization 不再调用它**
- 不要大范围删除 Zoo/examples/legacy scripts
- 最终 deprecation 留给 Phase 8
