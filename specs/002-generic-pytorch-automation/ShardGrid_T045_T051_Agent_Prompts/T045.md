# T045 — Test generic checkpoint contract

Phase: Phase 5  
Priority: P0 BLOCKING  
Depends on: T044

## 目标

为 Generic Checkpoint 建立正式 contract tests，先固定正确语义，再实现后续 shard/merge 重构。

主要文件：

```text
tests/unit/test_checkpoint_generic_state.py
src/shardgrid/runtime/checkpoint.py
```

## 必须覆盖

测试至少覆盖：

- checkpoint schema version
- graph fingerprint
- plan ID
- step
- worker/rank/GPU/owned partitions
- parameter entries：canonical ID + 原始 `state_dict` key + shape + dtype
- buffer entries：canonical ID + 原始 `state_dict` key + shape + dtype
- duplicate canonical ID
- duplicate original state key
- missing parameter/buffer
- shape mismatch
- dtype mismatch
- shared/tied parameter canonical owner
- strict reload expectation

Contract failure 必须明确属于 checkpoint stage，不能静默生成错误 artifact。

## 边界

- 本 Task 以测试为主，不提前完成 T046/T047 的 shard/merge 实现。
- 不修改 JobManager finalization。
- 不引入模型名称判断。
- 不实现 optimizer-state merge。

## 测试

```bash
pytest tests/unit/test_checkpoint_generic_state.py
```

PASS 条件：contract failures 被明确识别，测试能够约束后续 Generic Checkpoint 行为。
