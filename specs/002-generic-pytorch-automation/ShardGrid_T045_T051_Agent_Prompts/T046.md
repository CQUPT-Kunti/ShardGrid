# T046 — Save original state keys in worker shards

Phase: Phase 5  
Priority: P0 BLOCKING  
Depends on: T045

## 目标

扩展 Worker checkpoint shard，使其包含足够信息，在**不重新构造模型**的情况下完成架构无关 merge。

主要文件：

```text
src/shardgrid/runtime/checkpoint.py
tests/unit/test_checkpoint_generic_state.py
```

## 必须实现

`save_worker_state_shard()` 或当前等价路径必须保存：

- schema version
- graph fingerprint
- plan ID
- step
- worker ID / rank / GPU ID
- owned logical partitions
- parameter：canonical state ID、原始 `state_dict` key、tensor、shape、dtype
- buffer：canonical state ID、原始 `state_dict` key、tensor、shape、dtype
- ownership evidence

必须保持 schema versioning。

Shared/tied state：

- 一个 canonical state object
- 一个 checkpoint owner
- 不允许多个 Worker 重复声明 canonical owner

## 禁止

- 不在 shard 中只保存 module-local 临时名字而丢失原始 state key。
- 不依赖 `build_zoo_model()` / model name。
- 不开始 T047 merge 重构。
- optimizer state 仍然 Out of Scope。

## 测试

```bash
pytest tests/unit/test_checkpoint_generic_state.py
```

PASS 条件：shard 中已有足够 metadata 支持 architecture-free merge。
