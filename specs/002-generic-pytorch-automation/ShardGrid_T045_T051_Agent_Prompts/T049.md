# T049 — Verify final model state reloads

Phase: Phase 5  
Priority: P0 BLOCKING  
Depends on: T047, T048

## 目标

增加 integration test，证明非 Zoo 普通 PyTorch 模型训练后的最终 `model-state.pt` 可以被原始模型严格加载。

主要文件：

```text
tests/integration/test_generic_checkpoint_reload.py
tests/fixtures/ordinary_training_scripts/
```

## 必须验证

针对已支持的普通 PyTorch fixture/project：

```python
state = torch.load("model-state.pt")
original_model.load_state_dict(state, strict=True)
```

必须 PASS。

至少验证：

- Parameter key 完整
- Buffer key 完整
- shape/dtype 正确
- 没有 unexpected keys
- 没有 missing keys
- checkpoint 不依赖 Zoo/model name 才能加载

可以覆盖多种普通模型结构，但不要扩大为硬件测试。

## Out of Scope

必须明确断言/记录：

```text
optimizer state merge = not provided in this feature
```

不要因为 strict model reload 成功就顺手实现 optimizer checkpoint。

## 测试

```bash
pytest tests/integration/test_generic_checkpoint_reload.py
```

PASS 条件：

```text
STANDARD_STATE_DICT_STRICT_LOAD=PASS
```
